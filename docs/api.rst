.. _api_index:

=========
API Index
=========

Every class, function and method these pages document, grouped by module and
linked to where it is described. The list is generated from the documentation
itself when it is built, so it cannot fall behind it: a name documented
anywhere is listed here, and the test suite fails on a public class or
callable documented nowhere, unless it is listed as internal with its reason.

Callables are shown with ``()``. Enum members are not listed one by one --- the
streaming field enums hold hundreds --- and each enum says how many members it
has instead; follow the link to see them.
